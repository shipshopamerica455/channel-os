THE SETTINGS, FROM CANVA'S OWN DOCS
· PDF Standard — 96 DPI, "for multi-page and text-heavy documents". Use this.
· PDF Print — 300 DPI, "for printing". Not for something read on a screen.
· Flatten PDF — Canva notes it "may increase file size", AND it turns pages
  into images, so every link in your contents page stops working.
· Compress PDF — a third option for reduced size, paid accounts only.
· Page size: 1200 x 1600 px (3:4) reads far better on a laptop than A4.
· Contents links: select the text, link, then CHOOSE THE PAGE — not a URL.
  Build the contents page LAST, because links point at page numbers.
