## Pinned comment

> The bit worth knowing even if you never make a scrapbook:
>
> **Cropping in Canva is hiding, not deleting.** The photo is whole underneath;
> the crop is a window over it. Canva's own help centre puts it plainly — if you
> download a design containing cropped images to PDF, *"the PDF format will
> include the original image… someone could use a third-party tool (for example,
> a PDF editor) to get the full, uncropped image from your PDF export."*
>
> In a family album that is a privacy problem, not a design one. Anyone you
> cropped out is still in the file you emailed round.
>
> **The fix is one checkbox: Share → Download → tick Flatten PDF.** Canva:
> flattening *"converts the file into a static image, preventing editing in
> software like Adobe Acrobat."* Two costs — the file gets bigger, and
> accessibility tagging is removed, so leave it unticked if the document has to
> work with a screen reader.
>
> Full kit (the template + the six layouts + the export checklist):
> https://geniusjunkie.net/scrapbook-photo-book-kit/
