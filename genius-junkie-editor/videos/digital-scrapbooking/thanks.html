The order to do this in

  1. Pick your size and do not change it. 12 × 12 for a print shop or a physical album; US Letter if it is going through a home printer. An exported PDF cannot be brought back into Canva as an editable design, so this decision is permanent.
  2. Collect the photos into one folder first, then upload in one go. Check the limits sheet — each image under 50 MB, and a Canva Free folder holds 200 items.
  3. Pour photos into the layouts. Do not redesign each page. That is the whole time saving.
  4. Write one or two lines per spread. Prompts sheet if you are staring at an empty box.
  5. Export using the checklist, and tick Flatten PDF.

⚠️ The one thing people regret

Cropping is hiding, not deleting. An unflattened PDF still contains the whole original of every photo you cropped — that is Canva's own documentation, not a rumour. In a family album it is a privacy issue: anyone you cropped out is still in the file.

Share → Download → tick Flatten PDF. Canva: it "converts the file into a static image, preventing editing in software like Adobe Acrobat".

Two costs: the file gets bigger, and accessibility tagging is removed — so if the document has to work with a screen reader, leave it unticked and clean the crops by hand instead.

Printing it

  • Print shop: PDF Print (300 dpi), bleed ON, crop marks on, flattened. Ask whether they want CMYK.
  • Home printer: PDF Print, bleed OFF — a home printer cannot print to the edge, and bleed gives you a white border and a cropped page.
  • Family, on a screen: PDF Standard (96 dpi), flattened. Far smaller file.
  • On Canva Pro: Advanced settings → download pages as separate files gives a zip with one PDF per page, which is what most printers want.

If it gets big

A Canva design holds up to 350 pages. Past that, Canva's own advice is to build a second design and merge the two downloads with any file merger — so keep the page size identical between them and number your pages before you split.
