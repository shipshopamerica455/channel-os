⚠️ First — can you use Bulk Create?

It is a Canva Pro feature and it is desktop only, so it will not appear on your phone at all.

But Canva for Education is free for verified K-12 teachers and includes the whole Pro feature set, so Bulk Create is included. Verify with a school email at canva.com/education — it usually takes a day or two.

Without Pro or Education the template still works perfectly. You just fill the names in by hand.

How to use it

  1. Write the award line and the reason. Those never change, so they are not connected to anything.
  2. Leave NAME, COURSE and DATE exactly as they are — those are the placeholders Bulk Create connects to. Restyle them if you like, but keep them as separate boxes, and keep NAME centred and fixed width.
  3. Fill in the data sheet using the headings from the PDF. Clear the sample data first.
  4. Then Edit → Bulk create, or Apps → Bulk create.

The setting that makes it worth doing

At the connect step there is a Continue button, and below it, in small text, Advanced options. Open it:

  • Output → Individual designs (the default is one design with many pages)
  • Name each page using → your Name column
  • Save in → a folder you made for this run

That gives you one folder holding fifty separate files, each named after the person on it. The default gives you one long file and an hour of renaming.

Three that catch people

  • Multi-page templates need the data connections set on every page — the front generates perfectly and the back comes out blank.
  • Auto-match can be wrong. Read the connections before you continue; it can put the date where the course should be.
  • Images must be embedded in the cell, not linked. Canva's docs: image URLs from cloud storage "are not supported and will be treated as plain text" — so a Drive link prints the URL across your certificate.
