## Description

Bulk Create turns a spreadsheet into finished designs — fifty names, one click.
But almost everybody runs it, gets one enormous fifty-page file back, and then
spends an hour working out which page belongs to which person.

There is one setting that fixes that completely, and it is hidden underneath the
Continue button, which is why almost nobody finds it.

⚙️ **Advanced options** → set **Output** to **Individual designs**, and **Name
each page using** to your name column. You get a folder of fifty separate files,
each named after the person it belongs to. The default — "1 design with multiple
pages" — is what gives you the fifty-page document.

🧱 And the thing that decides whether Bulk Create works at all: it connects one
data field to one element, so **everything that changes between certificates has
to be its own separate text box**. Type "Awarded to ______" as a single box and
you cannot connect just the blank half — Canva has no way to reach inside it.

💷 Honest bit up front: **Bulk Create is a Canva Pro feature, and desktop only.**
BUT Canva for Education is free for verified K-12 teachers and includes the Pro
feature set, so Bulk Create is included — verify with a school email at
canva.com/education. Without it the template still works; you fill names in by
hand.

📏 The real limits, from Canva's docs: up to **150 data fields**, and up to
**300 rows** per run from a Canva Sheet. A whole school hits that ceiling — split
it by year group.
