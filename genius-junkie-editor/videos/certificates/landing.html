Fifty certificates in the time it takes to make one

Bulk Create turns a spreadsheet into finished designs — fifty names, one click. But almost everybody runs it, gets one enormous fifty-page file back, and then spends an hour working out which page belongs to which person. There is one setting that fixes that completely, and it is hidden underneath the Continue button. This is the whole build from the tutorial, ready to edit.

The mistake this saves you from

Bulk Create connects one data field to one element. So everything that changes between certificates has to be its own separate text box. Type "Awarded to ______" as a single text box and you cannot connect just the blank half — Canva has no way to reach inside it, so connecting the field replaces the whole line, including the words "Awarded to". The template in this kit is already built the right way.

And the setting nobody finds

At the connect step there is a big Continue button, and underneath it, in small text, Advanced options. Open it and set Output to Individual designs and Name each page using to your name column. You get a folder of fifty separate files, each named after the person it belongs to — instead of one fifty-page document and an hour of renaming.
