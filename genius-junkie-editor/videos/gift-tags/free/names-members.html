The rule — from Canva's own help page

"Each row creates one version of your design." With the output set to one design with multiple pages, that is a separate page for every row. So one "Name" column with thirty names is thirty pages — and thirty sheets of card when you print.

The fix — ten columns, one row per sheet

  1. Build the sheet: a design the size of your paper (Letter 8.5 × 11 in, or A4). File → Rulers and guides → Add guides → Custom: 2 columns, 5 rows.
  2. Design one tag, keep everything about 8 mm inside it, then group, duplicate and fill all ten cells.
  3. Give it ten separate name boxes — Canva's help: "For text, add a separate text box for each field."
  4. Open the names sheet. Fill Name 1 to Name 10 across each row, top-left tag first, then across, then down.
  5. Bulk Create → add the data → Match and fill fields. Check every box went to the right column. Then Create.

Thirty names = three rows = three sheets. A part-filled last row is fine — those tags print with a blank To line, spares to write by hand.

No Bulk Create?

Canva's help lists it for Pro, Teams, Business, Enterprise, Education and Nonprofit — not Canva Free. Everything else here is free: type the ten names, then duplicate the page for the next ten. Thirty names is about ten minutes.

Print and cut

  • Download as PDF Standard. Crop marks (PDF Print) only mark the edge of the page — on this layout the page edge is already a cut edge.
  • Print at 100% / Actual size, never "Fit to page" — that shrinks every tag.
  • One test on plain paper first. Check your printer's manual for the thickest card it takes.
  • Five cuts: one down the middle, then four across each strip. Punch the hole well clear of the edge.
