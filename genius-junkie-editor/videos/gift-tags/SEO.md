## The trap

Canva Help, "Create designs in bulk" (read 2 Nov 2026): *"Each row creates one
version of your design"*; output "1 design with multiple pages" = a separate page
per row. One Name column → one page per name → one sheet of card per tag. Fix:
*"For text, add a separate text box for each field"* — ten boxes, ten columns
(Name 1–10), one row per sheet. Plans: Pro, Teams, Business, Enterprise,
Education, Nonprofit — not Free.
