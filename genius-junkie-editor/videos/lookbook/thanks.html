⚠️ The one thing to get right

Canva's CMYK option is Pro-only. Their help page describes PDF Print as offering a "color profile (RGB or CMYK) selection option", and the same page lists CMYK colour profile options among the features restricted to Pro, Teams, Education and Nonprofit. On a free plan your file leaves in RGB.

That is not fatal — it just means you have to tell the printer. Export PDF Print, say in writing that the file is RGB, ask them to convert, and ask for a proof. The print-shop brief above has the wording.

The order to do this in

  1. Set the page size first. Changing it later reflows everything.
  2. Build one spread properly, then duplicate and swap the photos. One grid across the book is what makes it read as a house style.
  3. Drag backgrounds past the edge of the canvas. That overhang is what gets trimmed.
  4. Check every photo at 100% zoom. Soft in the editor is worse on paper.
  5. Export twice — PDF Print with bleed and crop marks for paper, PDF Standard under 10 MB for screens. Name them clearly.
  6. Ask for a proof before the full run.
