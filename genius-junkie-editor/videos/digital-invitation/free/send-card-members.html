Where the tap survives — from Canva's own help page

From Canva Help, "Add hyperlinks": "Links remain clickable by downloading your design as a PDF or by presenting it." And: "Hyperlinks will not work on PNGs, JPGs, MP4s, etc., or when you post your design on social media."

  • Published website: works — send the link
  • PDF (standard): works — but not a flattened PDF
  • Presenting: works, only while you present it yourself
  • PNG / JPG: dead — "Image formats like JPG and PNG do not support hyperlinks regardless of the image source"
  • MP4 video: dead — "hyperlinks are only clickable in the Presenter window while on Presenter view"
  • Posted to social media: dead

A picture of an invitation is a picture. Send the link — and the picture only as a teaser.

The build — three pages, one website

Start from a website template (search "website") — not a poster, not a post, and not a mobile site or link in bio, which Canva says publish to a canva.link address only. When it is published, each page appears as "a separate scrollable page on the same website".

  • Page 1 — the envelope. Big, a seal with the initial, and the words: You're invited — tap to open.
  • Page 2 — the opened card. What, when, where — one line each, readable without zooming.
  • Page 3 — the details. The address with a map button, the reply button, dress code, parking, gift list.

Link it: select the envelope → More → Link → Pages in this document → page 2. Do the same for the words. Keep them as separate pieces so a tap anywhere near the envelope opens it.

Publish it free — two limits to know

Publish website → site address (keep it short) → Settings → turn on Resize on mobile → Continue → Publish.

  • "Canva Free users can have up to five live websites on the free domain." Unpublish an invitation after the event and the slot is yours again.
  • Canva Free publishes up to 10 sections per page. If something is missing on the published site, check that first.

Seven checks before a single guest sees it

  1. It was made from a website template
  2. The envelope and the words both link to page 2
  3. Page 2 links to the details page
  4. Every button on the details page goes where it says
  5. You opened the published link on a phone, from a message, and tapped through every page
  6. Every line is readable with the phone at arm's length
  7. You are sending the link — not the PNG, not the MP4

The fifth is the one nobody does — everything works in the editor. Your guests are not in the editor.
