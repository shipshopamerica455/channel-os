The half of a pitch deck nobody teaches

Every tutorial shows you how to lay one out. Almost none of them tell you what happens to the file after you send it — which is the only part an investor actually experiences. A pitch deck is not a presentation you give. It is a file that gets forwarded, opened without you in the room, and read in silence on somebody's phone. This is the whole deck from the tutorial, ready to edit.

What's inside

  • The editable Canva deck — ten slides at 1920 × 1080, in the order that works: title, problem, solution, how it works, market, business model, traction, competition, team, the ask. Type sizes and margins are set once so the deck cannot drift as you add slides.
  • The ten-slide brief — one line on what goes on each slide, and the question each one has to answer. Printable.
  • The traction worksheet — get the numbers straight before you design the slide: the metric, the window it covers, where it came from, and the honest version if it is small.
  • The send checklist — the pre-send checks, with both file traps called out in full.
  • The three emails — the cold intro, the reply to a warm introduction, and the single follow-up after silence.

The mistake this saves you from

You crop a screenshot so an investor cannot see a number you are not ready to share. You export the deck as a PDF and send it. The number is still in the file. This is not a rumour — it is in Canva's own documentation: a PDF export "will include the original image", so anybody can open your deck in a PDF editor and pull the full uncropped picture straight back out. The crop is a mask. It hides the pixels; it does not delete them.

The fix is one checkbox — Flatten PDF — which converts the file to a static image, locks your fonts, and stops anyone editing your deck in Acrobat. The kit shows you exactly where it is, and the second checkbox sitting right next to it that quietly emails an investor every private speaker note you wrote to yourself.

And if they ask for PowerPoint

Canva's own warning is that PPTX files "may look different when opened in Microsoft PowerPoint", that you may need to install the fonts you used, and that animations and embedded videos are not supported at all. That is why the deck ships in a system font — so an editable copy survives the trip. The read-me explains when to send PPTX and what to say when you do.

Who it's for

Founders raising for the first time, and anyone who has been asked to "send the deck over" and wants it to arrive looking the way they built it. It assumes nothing but a free Canva account.
