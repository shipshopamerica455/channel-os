```
Cricut publishes a list of things an SVG file is not allowed to contain, and
Canva makes several of them by default.

From the Design Space help pages: an .svg cannot contain pattern fills,
clipping paths, editable text, or linked images. And a clipping path is their
term for "multiple shapes layered together so that one shape masks or clips the
other shapes" — which is exactly what every Canva frame is, and every photo you
have dropped into a shape.

So you pay for Canva Pro to unlock the SVG download, you export, you upload,
and Design Space says "Your file includes unsupported items." That is the whole
message. No clue which part.

And the other half of the time it uploads perfectly and cuts a rectangle,
because the thing you drew was never a vector — and Canva does not label which
elements are.

THE RULES, FROM CRICUT'S AND CANVA'S OWN PAGES
· An .svg or .dxf cannot contain pattern fills, clipping paths, editable text,
  or linked images. The error is "Your file includes unsupported items."
· "SVGs are restricted to 5000 paths; more than 5000 will cause an upload
  error to occur."
· Design Space accepts .svg, .jpg, .bmp, .png, .gif and .dxf. The raster types
  upload as a single layer; .svg and .dxf are "cut-ready images that upload as
  designed" and separate into layers.
· "transparent PNGs and SVGs are available to accounts with the Canva Pro,
  Canva for Teams, Canva Education, and Canva for Nonprofits plans." — Canva
· Weld "joins shapes… by removing any overlapping cut lines… wherever cut
  paths have intersected, only the exterior cut path will remain" — and once a
  project has been welded and saved, it cannot be unwelded. — Cricut
Verified 5 October 2026.

GOOD NEWS YOU DID NOT ASK FOR: Canva converts text to outlines automatically on
SVG export, which satisfies Cricut's no-editable-text rule by itself. The catch
is that every letter is then its own closed shape — so script fonts need
welding in Design Space.
```
