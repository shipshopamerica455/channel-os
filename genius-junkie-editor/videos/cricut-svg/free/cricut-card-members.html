An .svg may not contain

  • Pattern fills
  • Clipping paths — Cricut's term for "multiple shapes layered together so that one shape masks or clips the other shapes"
  • Editable text — it has to be shapes
  • Linked images — images not embedded in the file

Every Canva frame is a clipping path. So is every photo you have dropped into a shape.

The error is "Your file includes unsupported items." It does not say which one, and it does not highlight anything. Look for a frame or a photo first — it is almost always that.

The six file types, and which ones cut

  • ✅ .svg and .dxf — "cut-ready images that upload as designed"; files built in layers separate back into layers automatically.
  • ❌ .jpg .png .bmp .gif — upload as a single layer. You can trace an outline around a picture, but you are not cutting the shapes you drew.

And the SVG download from Canva is paid: "transparent PNGs and SVGs are available to accounts with the Canva Pro, Canva for Teams, Canva Education, and Canva for Nonprofits plans." There is no workaround that keeps it a real vector.

The test Canva will not give you

Canva mixes true vector elements and raster ones in the same search results — the same way it mixes free and Pro — and it does not label them either way.

Drop the element on the canvas and scale it up to four or five times the page. A vector stays perfectly crisp. A raster goes soft, then blocky, and you will see it immediately. Two seconds per element.

Generally: flat single-colour shapes and line icons are vectors. Anything photographic, anything with a soft shadow baked in, anything painted or textured, is not.

The ceiling, the weld, and the colours

  • "SVGs are restricted to 5000 paths; more than 5000 will cause an upload error to occur."
  • A path is roughly one outline. A simple icon ~3. A script word: one per letter. A mandala, a wreath or a halftone: thousands — and a texture overlay on its own can blow the whole budget.
  • ✅ Canva converts text to outlines on SVG export, so Cricut's no-editable-text rule is handled for you.
  • ❌ …but every letter is then its own closed shape. Script fonts where letters touch need Weld in Design Space.
  • Weld "joins shapes… by removing any overlapping cut lines… wherever cut paths have intersected, only the exterior cut path will remain." It is one-way — once welded and saved, it cannot be unwelded. Duplicate first.
  • Each distinct fill colour becomes its own layer, and its own mat. In a cut file, colour is instructions, not decoration.

Seven checks before you export

  • No frames, no photos dropped into shapes — those are clipping paths
  • Every element passed the scale-up test and is actually a vector
  • Flat solid colours, one per intended piece of material
  • No shadows, gradients or textures
  • The background is deleted, not white
  • Not so detailed that it will tear even if it uploads
  • Every element came from a Canva search filtered to Free

The first is the one Design Space stops you for. The second wastes a sheet of vinyl without stopping you at all.
