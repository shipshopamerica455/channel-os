Cricut publishes a list of things an SVG file is not allowed to contain — and Canva makes several of them by default.

Pattern fills, clipping paths, editable text, linked images. And a clipping path is Cricut's own term for one shape masking another, which is exactly what every Canva frame is, and every photo you have dropped into a shape.

So you pay for Canva Pro to unlock the SVG download, you export, you upload — and Design Space says "Your file includes unsupported items." That is the whole message. No clue which part.
